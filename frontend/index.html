Get results without a LookinBody login

InBody 380 · Wi-Fi reported by the operator. No direct hardware connection has been verified. Use a USB export or import the printed result sheet without a LookinBody account.

  1. Insert a USB flash drive in an available InBody USB host port.
  2. On the device: Setup → 4. Data Management → Export Data as an MS Excel File.
  3. Select a test or date range, export, then move the USB drive to the clinic computer.
  4. Retain the original export in the local bridge review queue. CSV/Excel import recognizes explicit labels and units. Unrecognized columns and multi-test exports remain source evidence for manual review; vendor-specific mapping needs a sample export.

If the device Setup passcode is unavailable, import a photo or scan of the printed result while arranging an authorized reset with InBody support. A printer USB cable is not a PC data connection.
